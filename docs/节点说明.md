# 节点说明

## 1. 系统拓扑

### 1.1 推荐主链路（Xbox）
```
/joy -> dog_teleop/xbox_input_node -> /locomotion_cmd -> locomotion_core_node -> /joint_states + /gait_params -> real_motor_controller -> /motor_feedback
```

说明：
- `locomotion_core_node` 通过参数 `input_source` 限定只接受一个来源（当前主链路为 `xbox`）。
- 非选定来源的 `LocomotionCommand` 会被直接忽略。

## 2. 节点清单

### 2.1 `xbox_input_node`
- **源文件**：`dog_teleop/src/xbox_input_node.cpp`
- **节点名**：`xbox_input_node`
- **订阅**：`/joy`（`sensor_msgs/msg/Joy`）
- **发布**：`/locomotion_cmd`（`dog_msgs/msg/LocomotionCommand`）
- **功能**：将 Xbox 手柄输入映射为统一运动指令。
- **摇杆/轴映射**：
  | 轴 | 功能 | 备注 |
  |---|---|---|
  | `axes[1]` | 前后速度 vx | 反向映射 |
  | `axes[0]` | 左右速度 vy | — |
  | `axes[7]` | 机身升降 | +1.0 = 抬高 |
  | `axes[6]` | 偏航旋转 | — |
  | `axes[5]` | RT 门控 | 按住才可切换步态 |
- **按键映射**：
  | 按键 | 步态 |
  |---|---|
  | A (`buttons[0]`) | STAND |
  | B (`buttons[1]`) | STEPPING |
  | X (`buttons[2]`) | WALK |
  | Y (`buttons[3]`) | TROT |
- **参数**：
  | 参数 | 默认值 | 说明 |
  |---|---:|---|
  | `joy_deadband` | `0.08` | 摇杆死区 |
  | `mode_gate_threshold` | `-0.5` | RT 门控阈值 |
  | `mode_gate_less_than` | `true` | RT < 阈值时允许切步态 |
  | `vx_max_walk` | `0.18` | WALK 最大前进速度 (m/s) |
  | `vx_max_trot` | `0.42` | TROT 最大前进速度 (m/s) |
  | `vy_max_walk` | `0.03` | WALK 最大侧移速度 (m/s) |
  | `vy_max_trot` | `0.05` | TROT 最大侧移速度 (m/s) |
  | `yaw_rate_max` | `0.35` | 最大偏航角速度 (rad/s) |
  | `height_min` | `0.24` | 最低机身高度 (m) |
  | `height_max` | `0.32` | 最高机身高度 (m) |
  | `height_default` | `0.31` | 默认机身高度 (m) |
  | `height_step_per_input` | `0.005` | 每次输入高度变化量 (m) |

### 2.2 `locomotion_core_node`
- **源文件**：`src/locomotion_core_node.cpp`
- **节点名**：`locomotion_core_node`
- **订阅**：`/locomotion_cmd`（`dog_msgs/msg/LocomotionCommand`）
- **发布**：
  - `/joint_states`（`sensor_msgs/msg/JointState`）— 12 关节位置指令
  - `/gait_params`（`std_msgs/msg/String`）— 当前步态名（STAND / STEPPING / WALK / TROT）
- **定时器**：5 ms（200 Hz）控制循环
- **功能**：
  - 开环步态规划 + 逆运动学 + 安全限幅
  - 步态转换平滑混合（可配置过渡时长）
  - 命令超时自动回 STAND
  - 指令一阶低通滤波 + 斜率限制
  - 支持 Joint_3 × 2.0 传动换算
  - STEPPING 可配置为严格直上直下模式
- **参数**：
  | 参数 | 默认值 | 说明 |
  |---|---:|---|
  | `input_source` | `"xbox"` | 生效输入源 |
  | `cmd_timeout_s` | `0.25` | 指令超时回 STAND (s) |
  | `thigh_length` | `0.21` | 大腿连杆长度 (m) |
  | `shank_length` | `0.21` | 小腿连杆长度 (m) |
  | `stand_foot_x_front` | `0.06` | 前腿站立足端前向偏移 (m) |
  | `stand_foot_x_rear` | `0.095` | 后腿站立足端前后偏移，按当前 IK 内部口径取正值 (m) |
  | `stand_foot_y` | `0.115` | 站立足端横向外张偏移 (m) |
  | `height_default` | `0.31` | 默认站立高度 (m) |
  | `height_min / max` | `0.24 / 0.32` | 高度边界 (m) |
  | `step_height_stand` | `0.0` | STAND 抬腿高度 (m) |
  | `step_height_stepping` | `0.050` | STEPPING 抬腿高度 (m) |
  | `step_height_walk` | `0.050` | WALK 抬腿高度 (m) |
  | `step_height_trot` | `0.050` | TROT 抬腿高度 (m) |
  | `step_freq_stepping` | `2.0` | STEPPING 步频 (Hz) |
  | `step_freq_walk` | `1.5` | WALK 步频 (Hz) |
  | `step_freq_trot` | `1.8` | TROT 步频 (Hz) |
  | `joint_limit_deg` | `105` | 关节偏移限幅 (°) |
  | `joint3_cmd_min / max` | `-0.8 / 1.8` | Joint_3 指令限幅 (rad) |
  | `joint1_x_coupling_gain` | `0.0` | J1 前后耦合增益 |
  | `joint1_yaw_coupling_gain` | `1.0` | J1 偏航耦合增益 |
  | `yaw_step_gain` | `1.0` | 偏航切向步幅缩放 |
  | `yaw_step_gain_in_place` | `1.2` | 原地转向切向步幅缩放 |
  | `in_place_turn_vx_threshold` | `0.03` | 原地转向 vx 阈值 (m/s) |
  | `in_place_turn_vy_threshold` | `0.02` | 原地转向 vy 阈值 (m/s) |
  | `max_step_length` | `0.16` | 非 WALK 步长上限 (m) |
  | `max_step_length_walk` | `0.14` | WALK 步长上限 (m) |
  | `foot_x_min_front` | `0.00` | 前腿足端 x 最小值 (m) |
  | `foot_x_min_rear` | `0.00` | 后腿足端 x 最小值，按当前 IK 内部口径定义 (m) |
  | `swing_scale_front` | `1.0` | 前腿 swing 行程缩放 |
  | `swing_scale_rear` | `1.0` | 后腿 swing 行程缩放 |
  | `stepping_strict_vertical` | `true` | STEPPING 强制竖直抬落 |
  | `stepping_diagonal_skew_rad` | `0.314` | STEPPING 对角相位差 (rad ≈ 18°) |
  | `command_filter_alpha` | `0.60` | 一阶低通滤波系数 |
  | `vx_slew_rate` | `1.20` | vx 斜率限制 (m/s²) |
  | `vy_slew_rate` | `0.60` | vy 斜率限制 (m/s²) |
  | `yaw_slew_rate` | `2.5` | 偏航斜率限制 (rad/s²) |
  | `height_slew_rate` | `0.05` | 高度斜率限制 (m/s) |
  | `gait_transition_duration_s` | `0.30` | 步态转换混合时长 (s) |

  **WALK 步长调参**：目标步长 ≈ `vx / step_freq_walk`，受 `max_step_length_walk` 上限约束。若需超 15 cm，可提高 `max_step_length_walk` 并按需调整 `vx_max_walk` 或 `step_freq_walk`。
  前后腿摆动不一致时，可在保持步频不变的前提下优先调 `swing_scale_front / swing_scale_rear`。

### 2.4 `real_motor_controller`
- **源文件**：`src/hardware/main.cpp`
- **节点名**：`real_motor_controller`
- **订阅**：
  - `/joint_states`（`sensor_msgs/msg/JointState`）
  - `/gait_params`（`std_msgs/msg/String`）
- **发布**：`/motor_feedback`（`dog_msgs/msg/MotorFeedback`）
- **硬件**：12 个 DJI 3508 电机（C620 电调），分布在 4 条 CAN 总线：
  | CAN 总线 | 腿 |
  |---|---|
  | `can0` | LF（左前） |
  | `can1` | RF（右前） |
  | `can2` | RB（右后） |
  | `can3` | LB（左后） |
- **控制循环**：5 ms（200 Hz），独立工作线程
- **控制模式**：
  - `HOLD_TARGET`：无指令时保持安全位姿
  - `ACTIVE_FOLLOW`：跟踪 `/joint_states` 指令
- **步态自适应 PID**：
  | 步态 | kp | kd |
  |---|---:|---:|
  | STAND | 60.0 | 3.0 |
  | STEPPING | 80.0 | 2.5 |
  | WALK | 45.0 | 2.5 |
  | TROT | 80.0 | 2.0 |
  | FAST_TROT | 60.0 | 1.5 |
- **安全策略**：
  - 指令超时 0.20 s 回 `HOLD_TARGET`（分组斜坡回位）
  - 软启动斜坡上电
  - **当前默认仅使能 LB（左后）3 电机**（其余注释关闭，按需开启）
- **CAN 总线初始化**（启动前执行）：
  ```bash
  sudo ip link set can0 type can bitrate 1000000
  sudo ip link set can0 up
  # 其余 can1–can3 同理
  ```

### 2.5 `pose_hold_tool`
- **源文件**：`src/pose_hold_tool.cpp`
- **节点名**：`pose_hold_tool`
- **发布**：`/joint_states`（`sensor_msgs/msg/JointState`），200 Hz
- **功能**：标定 / 调试工具，将机器人平滑移动到指定关节姿态。
  - 线性插值过渡，时长可配
  - 到达目标后可持续发布保持
  - 检测其他 `/joint_states` 发布者冲突并自动中止
  - 支持动态参数修改目标
- **参数**：
  | 参数 | 默认值 | 说明 |
  |---|---:|---|
  | `j1` | `0.0` | 全局 J1 默认角度 (rad) |
  | `j2` | `1.066` | 全局 J2 默认角度 (rad) |
  | `j3` | `0.087` | 全局 J3 默认角度 (rad) |
  | `lf_j1/j2/j3` | `NaN` | 左前腿独立覆盖 |
  | `rf_j1/j2/j3` | `NaN` | 右前腿独立覆盖 |
  | `lb_j1/j2/j3` | `NaN` | 左后腿独立覆盖 |
  | `rb_j1/j2/j3` | `NaN` | 右后腿独立覆盖 |
  | `duration_s` | `2.0` | 过渡时长 (s) |
  | `publish_hz` | `100.0` | 发布频率 (Hz) |
  | `hold_after_reach` | `true` | 到达后持续保持 |
  | `graph_wait_s` | `1.0` | 启动前等待 (s) |
  | `print_only` | `false` | 仅打印目标不发布 |

## 3. 接口与消息

### 3.1 Topic 接口矩阵
| Topic | 类型 | 发布方 | 订阅方 | 说明 |
|---|---|---|---|---|
| `/joy` | `sensor_msgs/msg/Joy` | `joy_node`（系统） | `dog_teleop/xbox_input_node` | Xbox 原始输入 |
| `/locomotion_cmd` | `dog_msgs/msg/LocomotionCommand` | `dog_teleop/xbox_input_node` | `locomotion_core_node` | 统一运动指令 |
| `/joint_states` | `sensor_msgs/msg/JointState` | `locomotion_core_node`、`manual_joint_pub`、`pose_hold_tool` | `real_motor_controller` | 12 关节位置指令 |
| `/gait_params` | `std_msgs/msg/String` | `locomotion_core_node` | `real_motor_controller` | 当前步态名 |
| `/motor_feedback` | `dog_msgs/msg/MotorFeedback` | `real_motor_controller` | — | 电机反馈（位置/速度/扭矩/温度） |

### 3.2 `LocomotionCommand.msg`
```
std_msgs/Header header
uint8 GAIT_STAND=0
uint8 GAIT_STEPPING=1
uint8 GAIT_WALK=2
uint8 GAIT_TROT=3
string source           # "xbox"
uint8  gait_mode
float32 vx              # 前进速度 (m/s)
float32 vy              # 侧移速度 (m/s)
float32 yaw_rate        # 偏航角速度 (rad/s)
float32 height          # 离地间隙偏移量 (m)
```

**语义说明**：`height` 是离地间隙偏移控制量，不是世界坐标系绝对 z。为保持操控手感，`height` 变小 = 机身抬高。

### 3.3 `MotorFeedback.msg`
```
std_msgs/Header header
string[]  name          # 关节名
float32[] position      # 关节位置 (rad)
float32[] velocity      # 关节速度 (rad/s)
float32[] torque        # 关节扭矩 (N·m)
float32[] temperature   # 电机温度 (°C)
```

## 4. 关节结构

4 条腿 × 3 关节 = 12 关节：

| 腿 | Joint_1（髋） | Joint_2（大腿） | Joint_3（小腿） |
|---|---|---|---|
| LF（左前） | LF_Joint_1 | LF_Joint_2 | LF_Joint_3 |
| RF（右前） | RF_Joint_1 | RF_Joint_2 | RF_Joint_3 |
| LB（左后） | LB_Joint_1 | LB_Joint_2 | LB_Joint_3 |
| RB（右后） | RB_Joint_1 | RB_Joint_2 | RB_Joint_3 |

关节限幅：J1/J2 ±1.2 rad，J3 -1.8 ~ +0.8 rad。

## 6. 坐标系约定
- `base_link` / `imu_link`：右手系，X 向前、Y 向左、Z 向上。
- `locomotion_core_node` 内部按 z_up 建模，IK 中显式处理几何映射。

---

## 7. 腿级内部模型
- 共享头文件 `motor_ros2/leg_model.h`：
  - `LegId`（LF / RF / LB / RB）、`JointId`（J1 / J2 / J3）
  - `LegJoints`、`QuadJoints` 类型
  - `flatten` / `unflatten`：腿级结构 ↔ 12 关节扁平数组双向转换
  - 统一关节元数据（顺序 / 符号 / 限幅）
- `locomotion_core_node`：内部按腿计算，发布前扁平化到 `/joint_states`。
- `real_motor_controller`：订阅后反扁平为腿级结构，按腿处理符号映射、限幅、小圈映射与下发。

## 8. 术语
| 术语 | 含义 |
|---|---|
| 零位 | 站立姿态下 12 电机 `pos=0` 的标定基准 |
| 站立位 | 控制参考姿态（几何站姿） |
| 偏移量 | IK 几何角到电机零位角的固定差值 |
| 门控 | 满足特定输入条件后才允许步态切换（Xbox 的 RT 条件） |
| 软启动 | 上电后斜坡过渡到保持位姿，防止电机突跳 |
