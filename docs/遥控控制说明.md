# 遥控控制说明（Xbox）

## 1. 目标
- 使用统一控制链路：`dog_teleop/xbox_input_node` 发布 `/locomotion_cmd`，`locomotion_core_node` 统一生成 `/joint_states` 与 `/gait_params`。
- 运行时只启用 Xbox 输入源。
- 坐标口径统一为右手系（`X` 前、`Y` 左、`Z` 上）。

## 2. 启动方式

### 2.1 Xbox 控制
1. 启动手柄驱动：
```bash
ros2 run joy joy_node
```
2. 启动控制链：
```bash
ros2 launch dog_control locomotion_control.launch.py input_source:=xbox
```

## 3. 输入映射

### 3.1 Xbox 映射（当前代码）
- `axis1`：前后速度 `vx`（前推为前进，节点内已做方向修正）
- `axis7`：高度调节 `height`（`axis7=+1.0` 表示抬高机身，对应 `height` 变小）
- `axis6`：转向 `yaw_rate`
- `axis5`：步态切换门控轴（满足阈值才允许切换）
- 按键：
  - `A` -> `STAND`
  - `B` -> `STEPPING`
  - `X` -> `WALK`
  - `Y` -> `TROT`

门控规则：
- 默认条件：`axis5 < -0.5` 时，A/B/X/Y 才会生效。

## 4. 核心行为说明
- `locomotion_core_node` 仅接收 `input_source` 指定来源，其他来源命令会被丢弃。
- `cmd_timeout_s` 超时后自动回 `STAND`。
- `height` 语义：
  - `height` 表示离地间隙（clearance）控制量，不是绝对 `z`。
  - 操作手感保持不变：抬高机身时 `height` 变小。
- `STEPPING` 默认采用“严格直上直下”：
  - 强制 `vx=0, vy=0, yaw=0`
  - 足端 `X/Y` 固定在站立位置，仅垂向按轨迹抬落
  - 对角腿采用微相位差（默认 `8°`）减少同步冲击
- 关节安全处理：
  - 关节限幅 `joint_limit_deg`
  - `Joint_3` 发布口径限幅：`joint3_cmd_min/joint3_cmd_max`（默认 `-0.8/1.8`，对应下游反向后的目标口径）
  - `foot_x_min_front / foot_x_min_rear` 防止 `Joint_1` 因几何翻转突变
  - `joint1_x_coupling_gain` 用于抑制前后步态对 `Joint_1` 的耦合偏摆（默认 `0.0`）

推荐参数（`locomotion_core_node`）：
- `step_height_stepping=0.03`
- `stepping_strict_vertical=true`
- `stepping_diagonal_skew_rad=0.139626`
- `joint3_cmd_min/joint3_cmd_max=-0.8/1.8`

WALK 步长（>15cm）调参示例：
- `step_len ≈ vx / step_freq_walk`，且受 `max_step_length_walk` 约束。
- 示例：`max_step_length_walk=0.20`，并按需提高 `vx_max_walk` 或降低 `step_freq_walk`。

## 5. 常见问题排查

### 5.1 日志一直 `src=none`
- 现象：`locomotion_core_node` 输出 `src=none ... timeout=1`
- 排查：
  1. 是否启动了输入节点（`dog_teleop/xbox_input_node`）
  2. 是否有 `/locomotion_cmd`：
```bash
ros2 topic echo /locomotion_cmd
```
  3. `input_source` 是否与实际输入源一致

### 5.2 `src=xbox` 但一直 `STAND`
- 常见原因：`axis5` 门控未触发，A/B/X/Y 切步态无效。
- 排查：
```bash
ros2 topic echo /joy
```
确认门控轴为 `axes[5]` 且值满足阈值条件。

### 5.3 小跑时 `Joint_1` 明显朝一侧偏
- 优先检查：
  - `stand_foot_y` 是否正确（当前口径建议 `0.115`）
  - `stand_foot_x_front / stand_foot_x_rear` 是否与当前控制口径一致
  - `joint1_x_coupling_gain` 是否被改大
- 建议：
  - 先保持 `joint1_x_coupling_gain=0.0` 验证对称性
  - 若后腿摆动明显大于前腿，可单独上调 `swing_scale_rear`
  - 需要更多自然摆动时再小幅提高 `joint1_x_coupling_gain`（如 `0.1~0.3`）

### 5.4 原地踏步看起来不像“直上直下”
- 先确认模式确实是 `STEPPING`（不是 `WALK/TROT`）。
- 先确认参数：
  - `stepping_strict_vertical=true`
  - `step_height_stepping` 先用 `0.025~0.035`
- 若仍有明显扰动，优先排查机械零位和关节方向映射，再微调 `stepping_diagonal_skew_rad`（建议先围绕 `0.14` 附近小步调整）。

## 6. 实机安全调试建议
1. 默认先保持仅 `LF` 三电机使能。
2. 按“单腿 -> 对角两腿 -> 四腿”顺序扩展。
3. 优先验收 `STEPPING` 稳定，再做 `WALK/TROT`。
