# 机械结构说明（12 自由度串联狗）

## 1. 总体结构
- 机器人类型：四足串联腿结构。
- 自由度：每条腿 `3` 自由度（`Joint_1/2/3`），总计 `12` 自由度。
- 腿命名：
  - `LF`（左前）、`RF`（右前）、`LB`（左后）、`RB`（右后）。
- 重量11KG
- 电机额定扭矩6NM,峰值17NM(膝关节有1：2减速比)

## 2. 机械尺寸与零位基准（对外口径）
- 实测尺寸：
  - 前后 `Joint_1` 电机中心距：`300 mm`
  - 左右 `Joint_1` 电机中心距：`100 mm`
  - 前后足端间距：`500 mm`
  - 左右足端间距：`290 mm`
- 当前站立足端相对各自 `hip`（`Joint_1`）的位置（Joint_1 = 0，足端不外张）：
  - `LF = (x, y, z) = (+80, +95, -305) mm`
  - `RF = (x, y, z) = (+80, -95, -305) mm`
  - `LB = (x, y, z) = (-120, +95, -305) mm`
  - `RB = (x, y, z) = (-120, -95, -305) mm`
- 尺寸自检（按右手系、以上述 `hip` 中心距为基准）：
  - 前后足端间距：`80 - (-120) + 300 = 500 mm` ✓
  - 左右足端间距：`95 - (-95) + 100 = 290 mm` ✓
- J1 到足端直线距离与膝内角：
  - 前腿：`√(80² + 305²) ≈ 315 mm`，膝内角 `≈ 83°`
  - 后腿：`√(120² + 305²) ≈ 328 mm`，膝内角 `≈ 77°`
- 站立姿态说明：
  - Joint_1 锁零，四条腿不外张，保持平行。
  - 站立高度（J1 到地面）统一记为 `305 mm`（前后差几 mm，忽略）。
  - 四条腿膝关节弯曲方向一致（均向后弯）。
  - body 顶部到 J1 约 `60 mm`，机器人整体最高点约 `305 + 60 = 365 mm`。
- 零位定义：
  - 机器人站立时，12 个电机 `pos = 0`。
  - 运动控制以该站立零位为基准做偏移控制。

## 3. 已知机械问题
- **足端垂直虚位**：约 `20 mm`，来源于传动链间隙。
  - 影响：落地时刻不确定，站立腿高度有 ±10 mm 偏差。
  - 缓解措施：
    - 站立阶段依靠自重压实间隙（重力预紧）。
    - 摆动抬腿高度 ≥ 40 mm，避免虚位导致拖地。
    - 步态速度放慢，减少冲击。
  - 水平方向虚位很小，足端落地位置可信。

## 4. 关节命名与编号规则
- 每条腿按 `Joint_1 -> Joint_2 -> Joint_3` 从近端到远端编号。
- 关节名全集：
  - `LF_Joint_1` `LF_Joint_2` `LF_Joint_3`
  - `RF_Joint_1` `RF_Joint_2` `RF_Joint_3`
  - `LB_Joint_1` `LB_Joint_2` `LB_Joint_3`
  - `RB_Joint_1` `RB_Joint_2` `RB_Joint_3`

## 5. 坐标与控制约定
- 足端 IK 使用髋关节局部坐标（右手系）：
  - `X` 向前为正
  - `Y` 向左为正
  - `Z` 向上为正
- 左右腿对称：
  - 左腿 `+Y`，右腿 `-Y`
- 对外坐标口径：
  - `base_link` 与 `imu_link` 均按右手系解释（`X` 前、`Y` 左、`Z` 上）。

## 6. 当前控制默认参数（与新控制链路一致）
- 几何参数：
  - `thigh_length = 0.21 m`
  - `shank_length = 0.21 m`
  - `knee_gear_ratio = 2.0`（Joint_3 输出 2 倍换算）
  - `knee_offset_deg = 19.0`（大小腿并拢时的机械偏移角）
- 站立参数：
  - `stand_foot_x_front = 0.08 m`
  - `stand_foot_x_rear = 0.12 m`
  - `stand_foot_y = 0.095 m`（Joint_1 锁零，不外张）
  - `height_default = 0.305 m`（J1 到地面）
- 摆腿参数：
  - `swing_height = 0.04 ~ 0.05 m`（≥ 虚位 20mm 的 2 倍）
  - `swing_scale_front = 1.0`
  - `swing_scale_rear = 1.0`
  - `foot_x_min_front = 0.00 m`
  - `foot_x_min_rear = 0.00 m`
- Walk 步态参数：
  - `gait_period = 1.2 s`
  - `duty_factor = 0.8`
  - `step_length = 0.05 ~ 0.06 m`
  - `lateral_shift = 0.015 ~ 0.020 m`
  - 步序：`LF(0.0) → RB(0.25) → RF(0.5) → LB(0.75)`
- Joint_1 控制策略：
  - Walk 步态中 Joint_1 全程锁零，仅用 Joint_2/3 运动。
  - 转弯通过左右步长差实现，不使用 Joint_1。
- `height` 语义：
  - `LocomotionCommand.height` 与 `height_min/max/default` 表示"离地间隙（clearance）"控制量，不是世界系绝对 `z`。
  - 为保持操控手感，`axis7=+1` 与 `H` 仍表示"抬高机身"（对应 `height` 控制量减小）。
- 安全与传动：
  - 关节发布限幅：`±105°`
  - `Joint_3` 输出按 `2.0` 倍换算（对应当前传动比处理）
  - 膝关节机械偏移 `19°`（大小腿并拢时的初始角度）

## 7. 与 URDF 的差异声明
- 当前工程存在"实测尺寸"和"URDF 安装位姿"未完全同步的情况。
- 对外说明口径以实测值 `300(Joint_1前后) / 100(Joint_1左右) / 500(前后足端间距) / 290(左右足端间距) mm`、站立高度 `305 mm` 以及上述四腿足端相对 `hip` 坐标为准。
- URDF 主要用于可视化与联调，代码完全不需要考虑
